# React Native Projects

A collection of small mobile apps built with **React Native** and **Expo** while learning and experimenting with React Native development.

## Projects

* **Pokedex** — A simple Pokémon app.
* **Snake** — A classic Snake game built for mobile.

## Tech Stack

* React Native
* Expo v57.0.20
* TypeScript

## Getting Started

Clone the repository:

```bash
git clone https://github.com/saurabhravte/react-native-projects.git
cd react-native-projects
```

Navigate to any project and install dependencies:

```bash
cd pokedex
npm install
npm start
```

You can use the same steps for other projects in the repository.
